# Tech Stack

Key technology choices and architecture decisions for Recording Studio Tycoon.

## Frontend
- **Framework:** React 18 + TypeScript (strict off; `@/*` path alias)
- **Build Tool:** Vite 5 — **single config `vite.config.ts`** (do not reintroduce a
  second `vite.config.js`: it once stripped the `@` alias and broke the build).
  Includes `define: { global: 'window' }` and dev port 8080.
- **Styling:** Tailwind CSS + Radix UI primitives (shadcn-style components).
- **Rendering:** **pixi.js v8** — API notes: `new Application()` → `await app.init(...)`,
  append `app.canvas` (not `app.view`), `Graphics.poly/rect/circle(...).fill()/stroke()`,
  `roundRect` (not `roundedRect`), pointer events via `eventMode = 'static'`.

## State & Data
- **State Management:** React state in `pages/Index.tsx` via custom hooks
  (`useGameState`, `useGameLogic` + sub-hooks). No global store.
- **Persistence:** `localStorage` through `SaveSystemContext` (`useSaveSystem`).
- **Toasts:** `use-toast` bridges to **Sonner**; a single `<Toaster />` renders them
  in `App.tsx`.
- **Audio:** Web Audio via `utils/audioSystem` (`gameAudio`, `playSound`), assets in
  `src/audio/ui-sfx`; unlock happens on first user gesture.

## Architecture
- **UI split:** DOM dashboard (3 columns / swipe tabs) with an embedded **Pixi
  isometric studio room** (`WebGLCanvas` ← `StudioRoom`) as the diegetic home screen.
- **Data flow:** props-down from `Index` → `MainGameContent`; Pixi reads a state ref
  per animation frame (scene rebuilds only on resize/layout change).
- **Minigames:** `components/minigames/MinigameManager` (restored from git history),
  `MinigameType` union exported for triggers in `utils/minigameUtils`.

## Tooling / Workflow
- **Issue tracking:** **Beads** (`bd` CLI, embedded Dolt DB, prefix
  `recording-studio-tycoon`). Run all `bd` commands from this directory:
  `bd list`, `bd ready`, `bd update <id> --status in_progress|closed`,
  `bd create "<title>" -t task --parent <epic> --deps <issue>`.
  Workflow documented in `AGENTS.md` (generated by `bd init`).
- **Verification:** `npm run build` (must pass) + headless-Chrome smoke tests
  (Playwright driving system Chrome) before calling a slice done.
- **Notes:** ExFAT volume — `._*` AppleDouble files are ignored but cleaned with
  `find src -name '._*' -delete`; `rm -rf dist` before builds if `ENOTEMPTY` appears.
